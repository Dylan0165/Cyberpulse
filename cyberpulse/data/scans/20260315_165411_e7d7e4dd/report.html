Gedetailleerde Bevindingen

Kritiek DNS Zone Transfer Kwetsbaarheid DNS Zone Transfer
Beschrijving
DNS-zoneoverdracht (AXFR) is succesvol uitgevoerd vanaf alle drie nameservers (ns1.transip.nl, ns0.transip.net, ns2.transip.eu), wat 7 DNS-records blootstelt. Dit stelt een aanvaller in staat om het volledige DNS-zonebestand te downloaden, inclusief interne subdomeinen en netwerkstructuur.
Impact
Complete DNS-zone-informatie wordt gelekt, wat interne netwerktoewijzing en subdomeinen onthult. Dit vergemakkelijkt verdere aanvalsplanning en kan leiden tot subdomein-overname of interne netwerkverkenning.
Oplossing / Aanbeveling
Configureer nameservers om zoneoverdrachten te weigeren voor niet-geautoriseerde IP-adressen. Gebruik ACL's (Access Control Lists) op DNS-servers om alleen geautoriseerde secundaire nameservers toe te staan. Implementeer TSIG (Transaction Signature) voor geverifieerde zoneoverdrachten.
Referenties
CVE-1999-0532 · OWASP-2021-A05 · https://www.ietf.org/rfc/rfc2845.txt
Kritiek Blootgestelde Gevoelige Bestanden (.env, configuraties) Backup File Discovery
Beschrijving
Meerdere gevoelige bestanden zijn publiek toegankelijk via HTTP(S), waaronder .env, .env.local, .env.production, config.php, wp-config.php, en database configuratiebestanden. Deze bestanden bevatten vaak wachtwoorden, API-sleutels en andere geheimen.
Impact
Directe diefstal van databasewachtwoorden, API-sleutels, encryptiesleutels en andere gevoelige configuratiegegevens. Kan leiden tot volledige compromittering van applicaties, databases en externe services.
Oplossing / Aanbeveling
Verwijder alle gevoelige bestanden uit de webroot. Gebruik omgevingsvariabelen of beveiligde configuratiebeheersystemen. Configureer webserver (nginx) om toegang tot .env, .git, config.*, en andere gevoelige bestanden te blokkeren via location-blokken.
Referenties
CVE-2021-44228 · OWASP-2021-A05 · https://cheatsheetseries.owasp.org/cheatsheets/Configuration_Management_Cheat_Sheet.html
Kritiek Remote Code Execution via Command Injection Remote Code Execution
Beschrijving
Command-injectiekwetsbaarheden gedetecteerd via parameters zoals cmd, exec, command, execute, ping, etc. De server voert externe commando's uit wanneer speciaal gemaakte invoer wordt verzonden, wat bevestigd wordt door whoami-uitvoer.
Impact
Aanvallers kunnen willekeurige commando's uitvoeren op de onderliggende server met de rechten van de webserver (bijv. www-data of root). Dit leidt tot volledige serverovername, gegevensdiefstal en verdere laterale beweging.
Oplossing / Aanbeveling
Implementeer strikte inputvalidatie en parameterisatie voor alle systeemaanroepen. Gebruik whitelisting van toegestane commando's. Voer webserverprocessen uit met minimale rechten. Implementeer Web Application Firewall (WAF) regels om command-injectie te blokkeren.
Referenties
CVE-2021-44228 · OWASP-2021-A03 · https://owasp.org/www-community/attacks/Command_Injection
Kritiek Onbeveiligde Database Web Interfaces Database Exploitation
Beschrijving
Meerdere databasebeheerinterfaces zijn publiek toegankelijk zonder authenticatie, waaronder phpMyAdmin (/phpmyadmin), Adminer (/adminer), pgAdmin (/pgadmin), en CouchDB interfaces. Deze geven directe toegang tot databases.
Impact
Directe toegang tot databases, waardoor aanvallers gegevens kunnen lezen, wijzigen of verwijderen. Kan leiden tot volledige gegevensdiefstal, databasecompromittering en verdere escalatie naar het onderliggende systeem.
Oplossing / Aanbeveling
Verwijder ongebruikte database-interfaces uit productieomgevingen. Beveilig resterende interfaces met sterke authenticatie, IP-whitelisting en VPN-toegang. Gebruik aparte beheeromgevingen niet rechtstreeks blootgesteld aan internet.

Technische Details
